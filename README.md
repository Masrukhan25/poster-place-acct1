A vintage travel poster for **KALDRIS — The Harbor Inside the Glacier**: a harbor town carved inside a giant glowing ice-blue glacier, where sailing ships pass through an ice tunnel and warm golden windows light the ice walls under the aurora. Sail in through the ice, and sleep warm inside the glacier — the only harbor where the cold stays outside and the light stays in.

The entry program (`main.py`, standard library only) copies `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png`, validating size and dimensions first.
